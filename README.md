# E-Commerce Sales Analysis

## Project Overview

An Excel-based E-Commerce Sales Analysis project focused on analyzing sales, 
profit, orders, quantity, customer segments, product categories, 
sub-categories, regions, and discount performance.

## Key KPIs

- Total Sales
- Total Profit
- Profit Margin
- Total Orders
- Quantity Sold

## Key Insights

- Technology was the largest contributor to sales.
- Office Supplies generated the highest profit in the selected dashboard view.
- Machines were the top-selling sub-category.
- Sales and profit varied across different months.
- Higher sales did not always translate into higher profitability.
